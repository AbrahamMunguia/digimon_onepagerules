Delega esta tarea al agente `globalizacion` (definido en
[.claude/agents/globalizacion.md](.claude/agents/globalizacion.md)) usando la herramienta Agent
con `subagent_type: "globalizacion"`.

Contexto para el agente: este proyecto (ver [AGENTS.md](AGENTS.md) y
[README.md](README.md)) es un catálogo de Digimon en Next.js App Router. Necesita soporte i18n
para español e inglés con subrutas `/es` y `/en` (usando el segmento dinámico `app/[lang]`, no la
clave `i18n` de `next.config.js`, que es solo de Pages Router), traduciendo textos de UI —
navegación, botones, disclaimers, copy de páginas — sin tocar nunca los archivos bajo `data/`
(nombres de digimons y datos del catálogo). El navbar debe incluir un dropdown para cambiar de
idioma preservando la página actual.

Argumentos adicionales del usuario para esta ejecución (si los hay, tienen prioridad sobre el
alcance por defecto del agente): $ARGUMENTS

Si la herramienta Agent no reconoce `subagent_type: "globalizacion"` (por ejemplo, en una sesión
donde el subagente de proyecto aún no fue registrado), no te detengas a pedir permiso por eso:
sigue tú mismo las instrucciones completas de
[.claude/agents/globalizacion.md](.claude/agents/globalizacion.md) como si fueras ese agente, y
dilo explícitamente en tu respuesta.

Al terminar, verifica el resultado en el navegador (dev server) antes de reportar éxito: confirma
que `/`, `/es`, `/en`, y al menos una ruta anidada en ambos idiomas cargan, que el dropdown de
idioma funciona, y que ningún archivo bajo `data/` cambió.
